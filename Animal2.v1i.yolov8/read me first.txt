7. TRAINING SCRIPT
==================

The following Python code was used to train the custom wildlife
detection model:

------------------------------------------------------------

from ultralytics import YOLO
import torch

DATASET = r"E:\Projects\EDITH.ai\Animal2.v1i.yolov8\data.yaml"
OUTPUT = r"E:\Projects\EDITH.ai\models"

def main():

    print("====================================")
    print("      EDITH WILDLIFE TRAINING")
    print("====================================")

    print("GPU:", torch.cuda.get_device_name(0))
    print("CUDA:", torch.cuda.is_available())

    model = YOLO("yolo26n.pt")

    model.train(
        data=DATASET,
        epochs=30,
        imgsz=640,
        batch=4,
        device=0,
        workers=2,
        project=OUTPUT,
        name="edith_wildlife"
    )

    print("\n====================================")
    print("      TRAINING COMPLETED")
    print("====================================")

    print("Model saved inside:")
    print(OUTPUT + r"\edith_wildlife")


if __name__ == "__main__":
    main()

------------------------------------------------------------

9. WINDOWS TRAINING ISSUE
==========================

During the initial training process, a Windows multiprocessing error
occurred related to process spawning.

The training script was therefore placed inside:

if __name__ == "__main__":

This prevents the Windows multiprocessing issue and allows the
training process to start correctly.

Example:

results = model.predict(
    source=frame,
    conf=0.35,
    verbose=False
)


14. WHY THE CUSTOM MODEL WAS TRAINED
=====================================

A general-purpose YOLO model was initially tested for wildlife detection.

However, the general model produced incorrect wildlife classifications
for several animals.

Examples observed during testing included:

Lion -> Cow
Boar -> Sheep/Bear
Leopard -> Cat/Dog
Monkey -> Person/Bird

Because of these limitations, a custom wildlife dataset was used to
train a dedicated model containing the wildlife classes required by
EDITH.
